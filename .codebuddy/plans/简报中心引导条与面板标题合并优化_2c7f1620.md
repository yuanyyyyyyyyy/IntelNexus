## 用户需求

简报中心 UI 视觉杂乱，需修复两处设计问题。

## 产品概述

在现有「简报中心」页面上做两处精准视觉优化：引导步骤卡片消除悬停重叠，配置面板标题与添加表单合并为单卡片。

## 核心特性

- 引导条三张卡片改为「按钮即卡片」：静态仅显示序号+标题，鼠标悬停按钮时弹出唯一提示文字，不再出现虚线边框与背景卡片重叠。
- 数据源/订阅/关注三个面板的标题条（Sources / Subscribers / Watch）与下方「添加…」表单合并为同一张卡片（标题作卡片头，下方直接为表单），消除两个独立卡片叠放的割裂感。

## 技术栈

- 前端框架：Streamlit（Python）
- 样式：项目内 `intelnexus/core/ui/styles.py` 中自定义 CSS（作用域 `.bf-workbench-scope`）
- 文案：沿用 `intelnexus/ui/i18n.py` 现有 key，无新增

## 实现方案

### 问题①：引导卡片重叠

**策略**：移除「透明 `st.button` 叠加 `st.markdown` 视觉卡片」的 hack，改为每列仅渲染一个 `st.button`，按钮 `label` 直接含序号图标与标题（`"→ 配置数据源"` 等），`help=desc` 作为唯一悬停提示；用 CSS 把该 button 美化为带顶部色条的卡片（复用 `.bf-step--*` 三态配色）。这样静态卡片只显示标题与序号，悬停仅在按钮本身出现 tooltip，彻底消除重叠和虚线背景卡片。

**关键决策**：

- 保留 Streamlit `st.button` 作为唯一交互元素（维持点击跳转 `bf_expand_settings`/`bf_active_tab`/`bf_switch_tab` + `st.rerun` 逻辑不变）。
- 删除原 `st.markdown` 视觉卡片与 `margin-top:-46px` 负 margin，避免两层 DOM 重叠。
- CSS 新增 `.bf-workbench-scope` 作用域下的 `[data-testid="stButton"] > button.bf-step-btn` 卡片样式（padding、圆角、顶部色条、三态背景/边框），并移除旧的负 margin 叠加规则。

**性能/可靠性**：纯 CSS 调整，无新增渲染开销；`st.button` 复用现有回调，不影响数据流。

### 问题②：面板标题与表单合并

**策略**：三个面板函数（`render_data_sources_panel` / `render_subscriptions_panel` / `render_watch_categories_panel`）中，将 `.bf-label` 标题条作为卡片头保留在 `.bf-panel` 容器内，去掉其 `border-bottom` 重分隔线，改为卡片内顶部内边距；首个 `st.expander("添加…")` 与标题之间拉开间距，使整块视觉为「一张卡片（标题头 + 表单内容）」而非两张卡片。`.bf-panel` 容器边框/圆角/顶部色条（source 蓝 / sub 绿 / cat 紫）复用现状，不改动业务与二级 expander 逻辑。

**关键决策**：

- 仅移除 `.bf-label` 在 workbench 作用域内的 `border-bottom` + `padding-bottom`，将标题改为卡片内 header（保留 tag + title 排版），并给首个 expander 上方加间距，避免割裂。
- 不改动 `.bf-label` 第一处（非 workbench 作用域，其他页面可能复用）以避免回归；仅调整 L936-963 的 workbench 内副本。

## 实现注意

- 仅做 targeted 编辑，不重写大文件；改动后保持 `python -m py_compile` 通过。
- `.bf-step__desc` 类在引导条移除后若未被其他元素使用可保留（不影响）；新按钮卡片样式新增 `.bf-step-btn` 类以避免与旧 `.bf-step` 冲突。
- 点击跳转逻辑（session_state 三 key + rerun）必须完整保留，确保引导交互可用。

## 架构设计

仅涉及现有简报中心 UI 层的两个文件，无架构变更；延续「markdown 渲染 + CSS 作用域」现有模式。

## 关键代码结构

无新增接口/类型，仅调整函数内渲染与 CSS 选择器。

## 设计风格

延续简报中心现有低饱和米色/中性色系（workbench 主题），保持卡片化、顶部色条标识（source 蓝 / sub 绿 / cat 紫）。引导卡片改为单按钮卡片，悬停仅 tooltip；面板标题与表单合一，视觉层次收敛为「一张卡片」。

## 页面区块设计

### 引导条（3 步卡片）

- 每行 3 列等宽卡片，每列为一个 `st.button`（label = 序号圆圈 + 标题），整体有浅边框、圆角、顶部色条（完成=绿、当前=蓝、待办=灰）。
- 静态：仅显示序号与标题（如「→ 配置数据源」），无多余描述层。
- 悬停：浏览器原生 tooltip 在按钮上方显示描述文字（如「添加 RSS 或网页源，丰富采集面」），无背景卡片重叠。
- 点击：展开配置区并跳到对应 tab（保留）。

### 配置面板（Sources / Subscribers / Watch）

- 单卡片结构：`.bf-panel` 容器（带顶部色条、边框、圆角）内，顶部为 `.bf-label`（tag + 中文标题，无下边框分隔线，作为卡片头），其下直接为「添加…」expander 与「管理…」expander，卡片头与表单之间留 12-16px 间距，整体为统一一张卡片，不再像两张卡片叠放。
