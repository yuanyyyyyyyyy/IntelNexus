## 用户需求

简报中心当前是「生成主流程」与「一次性配置」混在一起的长垂直瀑布流，主操作 Generate 按钮卡在中间偏下、结果历史藏在 session_state 开关后，操作繁琐且不直观。用户已确认选择方案 A：把生成主操作置顶可见、配置收进可折叠区、引导条可点击、历史常驻入口。

## 产品概述

简报中心（Workbench 风格）当前布局（`intelnexus/ui/briefing_viewer.py` 的 `render_briefing_center`）：引导条 → 关注点面板 → 数据源面板 → 订阅者面板 → 生成面板 → 预览 → 条目 → 历史。四个功能面板都用 `.bf-panel`（彩色标签条）平铺，生成按钮埋在第 4 位，历史还需 `st.session_state.show_briefing_history` 开关才显示。

重构目标：生成主流程一眼可见、配置可折叠、引导可点击跳转、历史常驻。

## 核心特性

1. 顶部生成区置顶：引导条下方直接放「生成」主导区（类目多选 + 推送开关 + 生成按钮同一行 columns），默认已填好，用户可直接点；模型选择收进「高级」expander，默认不展示。
2. 配置区可折叠 + 横向 tab：用单个大 `st.expander("设置：数据源 / 订阅者 / 关注点", expanded=False)` 收起三个配置面板；面板内部从纵向堆叠改为 `st.tabs` 横向切换（数据源 / 订阅者 / 关注点）。
3. 引导条可点击跳转：三个 step 做成可点，点击设置 `st.session_state.bf_expand_settings = True`（展开配置区）并记忆哪个 tab 应激活，当前步骤高亮。
4. 历史常驻入口：结果区加一个常驻「历史记录」toggle（切换 `st.session_state.show_briefing_history`），替代原来隐藏开关；结果区置于生成区下方自然展示。
5. 样式沿用现有 `:has(.bf-workbench-scope)` 作用域（`intelnexus/core/ui/styles.py` 的 `render_workbench_css`），不引入新全局样式、不破坏其他页面。

## 技术栈

- Python + Streamlit（UI 通过 `st.markdown` + 组件组合）
- 样式管理集中位于 `intelnexus/core/ui/styles.py`（`render_workbench_css` 使用 `--wb-*` 变量与 `.bf-*` 类）

## 实现方案

### 改动 1：生成主操作置顶（briefing_viewer.py）

- 在 `render_briefing_center()` 中，把 `_render_onboarding()` 之后的第一个区块改为新的 `render_briefing_generate_top()`：
- 用 `st.columns` 布局：类目 multiselect（占宽） + 推送 checkbox + 生成 primary 按钮 同一行。
- 复用 `briefing_runner.render_briefing_generate_controls`，为其新增 `top=True` 模式：当 `top=True` 时类目/推送/按钮用 columns 横向排布，模型选择收进 `st.expander("高级", expanded=False)`。
- 结果区 `render_briefing_preview()` / `render_briefing_entries()` 紧跟生成区之下。

### 改动 2：配置区收进可折叠 + 横向 tab（briefing_viewer.py）

- 新增 `render_briefing_settings()`：外层 `with st.expander(get_text("briefing_settings"), expanded=st.session_state.get("bf_expand_settings", False))`，内部 `tabs = st.tabs([数据源, 订阅者, 关注点])`，三个原有面板函数 `render_data_sources_panel / render_subscriptions_panel / render_watch_categories_panel` 分别放进对应 tab 的 `with tabs[i]:`。
- 保留 `.bf-panel` 包裹以延续彩色标签条风格，仅把它们之间的纵向堆叠改为 tab 切换。

### 改动 3：可点击引导条（briefing_viewer.py）

- `_render_onboarding()` 改为用 `st.columns(3)` + 每个 step 放一个 `st.button`，`on_click` 设置 `st.session_state.bf_expand_settings=True`；当前步骤高亮。

### 改动 4：历史常驻入口（briefing_viewer.py）

- 在结果区上方加一行：`st.toggle("显示历史记录", value=st.session_state.get("show_briefing_history", False), key="bf_history_toggle")` 并同步到 `st.session_state.show_briefing_history`，替代原隐藏开关；`render_briefing_history()` 守卫改为读该值。

### 改动 5：样式（styles.py）

- 现有 `--wb-surface` 已是 `#FFFFFF`（styles.py:781），背景无需改；本重构聚焦结构，样式沿用。
- 如横向 tab 与 `.bf-panel` 标签条视觉冲突，在 `render_workbench_css` 内微调 tab 面板透明背景、`.bf-panel` 在 tab 内 margin 收敛。

## 实现备注

- 不改动 `briefing_runner.py` 的 `_run_pipeline` / `_render_stats` 业务逻辑，仅扩展 `render_briefing_generate_controls` 的 `top` 参数。
- `render_briefing_history` 的 `show_briefing_history` 守卫改为由 toggle 控制。
- 用本地 `run.bat` 启动，进入简报中心 Tab 验证：生成区置顶、配置区可折叠、tab 切换、引导条点击展开、历史 toggle 生效。
