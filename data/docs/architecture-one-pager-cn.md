# IntelNexus — 项目架构一页纸

## 项目定位

**AI驱动的多源网络情报分析平台**，为网络安全/AI政策分析师自动化「搜索 → 分析 → 报告 → 推送」全流程。

## 数据流

### 搜索流程 (10步)

```
用户输入查询
    │
    ▼
① 模型预检 → ② Query扩展(中英互译+拼写纠正)
    │
    ▼
③ Registry调度 → ④ 并发搜索(15源) → ⑤ 跨源去重
    │
    ▼
⑥ 并行抓取网页 → ⑦ M-SCORE可信度评分 → ⑧ CIDAR冲突检测
    │
    ▼
⑨ 知识图谱构建(spaCy NER + NetworkX)
    │
    ▼
⑩ LLM生成结构化情报报告
```

### 简报流程 (5步)

```
6类情报类目 (AI政务/中国叙事/立法/数据泄露/漏洞/攻击)
    │
    ▼
① 并行采集 → ② LLM分析生成 → ③ 增量对比(delta diff)
    │
    ▼
④ 个性化过滤(按订阅者interests) → ⑤ 多渠道推送(邮件/企微/钉钉)
```

## 关键设计决策

### 1. Registry模式 (搜索源管理)

**问题：** 15个搜索源，格式各异，如果用if-else调度会是灾难性代码

**方案：** `BaseSearchSource` ABC + `SearchSourceRegistry` 统一调度

**效果：** 新增搜索源只需继承ABC实现search()，零改动调度层

### 2. Topic Registry双向飞轮 (架构核心)

**问题：** 搜索工具和简报工具是割裂的，用户搜索行为无法反哺简报

**方案：** Topic Registry作为枢纽，搜索查询可固化为Topic驱动简报，简报高危条目可触发取证搜索

**效果：** 用户越用越精准的正反馈飞轮

### 3. M-SCORE多维可信度评分

**问题：** 多源情报质量参差不齐，分析师难以快速判断可信度

**方案：** 4维评分(域名权威30%+新鲜度25%+深度25%+跨源一致性25%)

**效果：** 每条结果附带可信度分数，辅助决策
